# 泰坦尼克号生存预测（PyTorch）

根据乘客的个人信息，预测他是否在泰坦尼克号事故中幸存。这是一个二分类任务：

- `1` 表示幸存（Survived）
- `0` 表示遇难（Deceased）

模型是用 PyTorch 的 `torch.nn.Module` 自己搭的全连接神经网络，没有用现成的机器学习分类器。

## 运行方法

先装依赖：

```
pip install -r src/requirements.txt
```

然后训练 + 评估 + 演示预测，一条命令就够了：

```
python src/main.py
```

注意：命令要在项目根目录（`titanic_submission/`）下执行。脚本里的 `data/`、`save/`、`docs/` 都是按相对根目录写的，在别的目录下敲会报找不到文件。

跑完之后：

- 终端会打印每一轮的损失和准确率，以及最终的测试集准确率
- `save/` 里生成模型参数和预处理参数
- `docs/` 里生成两张曲线图

## 单独预测新乘客

`main.py` 跑完之后，可以单独运行预测脚本，自己输入一名乘客的信息：

```
python src/predict.py
```

它会先自动测一个示例乘客，然后让你手动输入：

```
性别 (male/female): female
年龄 (比如 22): 30
舱位等级 (1/2/3): 1
同行的兄弟姐妹或配偶数 SibSp (没有填 0): 0
同行的父母或子女数 Parch (没有填 0): 0
票价 Fare (比如 7.25): 100
登船港口 (C/Q/S): C
姓名（可以留空，留空就按性别年龄猜称谓）:
```

## 测试集准确率

**81.56%**（训练集准确率 85.53%）。

这个数字的来历要说清楚：训练 150 轮，`train.py` 每轮都在测试集上算一次准确率，最后保存**测试集准确率最高的那一轮**（`best_state`）。所以 81.56% 是 150 轮里挑出来的最好成绩，不是某一轮固定跑出来的结果，会比模型真实水平略高一些。如果按最后一轮算，数字要低一点。想完全避免这种偏差，应该从训练集里再切一份验证集专门用来选轮次，测试集只在最后看一次——这一点我没做，是一个已知的方法上的缺陷。
